# Presentation Guide

## วิธีใช้งาน

### ใช้ HTML (แนะนำ - ง่ายที่สุด)

1. เปิดไฟล์ `index.html` ด้วย browser (Chrome/Firefox/Safari)
2. ใช้ปุ่มลูกศร ← → หรือ Space เพื่อเลื่อนหน้า
3. คลิกขวาหน้าจอ = ย้อนกลับ, คลิกซ้าย = ไปต่อ

### ใช้ Marp (ถ้าต้องการแก้ไข)

```bash
# ติดตั้ง Marp CLI
npm install -g @marp-team/marp-cli

# แปลงเป็น HTML
marp slides.md -o slides-marp.html

# แปลงเป็น PDF
marp slides.md -o slides.pdf

# Preview
marp -p slides.md
```

## โครงสร้างไฟล์

```
presentation/
├── index.html   ← เปิดไฟล์นี้เลย (พร้อมใช้งาน)
├── slides.md    ← Marp source (ถ้าต้องการแก้ไข)
└── README.md    ← คู่มือนี้
```

## Keyboard Shortcuts

| ปุ่ม | การทำงาน |
|------|----------|
| → หรือ Space | หน้าถัดไป |
| ← | หน้าก่อนหน้า |
| Home | กลับหน้าแรก |
| End | ไปหน้าสุดท้าย |

## Tips สำหรับนำเสนอ

1. **เวลา 10 นาที = 20 slides** → ประมาณ 30 วินาที/slide
2. อ่านหัวข้อก่อน แล้วอธิบายเพิ่มเติม
3. ส่วนโค้ด - ไม่ต้องอ่านทุกบรรทัด แค่ชี้จุดสำคัญ
4. ถ้ามีคำถาม ตอบว่า "ขอเช็คโค้ดก่อนแล้วตอบทีหลังได้ครับ/ค่ะ"
