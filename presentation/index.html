🧠 TF-IDF คืออะไร?

เทคนิค AI สำหรับวิเคราะห์ข้อความ

TF = Term Frequency

คำนี้ปรากฏกี่ครั้งใน document นี้

เช่น "ระบบล่ม" ปรากฏ 3 ครั้ง → TF สูง

IDF = Inverse Document Frequency

คำนี้หายากแค่ไหนใน corpus ทั้งหมด

เช่น "Enterprise" หายาก → IDF สูง

วิธีใช้ในระบบนี้

  1. แปลง Ticket เป็น TF-IDF Vector
  2. แปลง Policy เป็น TF-IDF Vector
  3. คำนวณ Cosine Similarity
  4. เลือก Policy ที่ "คล้าย" มากที่สุด
💡 พูดง่ายๆ: TF-IDF = วิธีหาว่าข้อความไหน "คล้ายกัน" โดยดูจากคำที่ใช้

    # 1. สร้าง TF-IDF Vector จาก Policy ทั้งหมด

⚡ Agent #3: Priority Scorer

ให้คะแนนความเร่งด่วนตาม Policy

📄 app/agents/rules.py
def decide_priority(category, policies):
    priority = "P3"   # เริ่มจากปกติ
    escalate = False

    for pol in policies:
        if pol["priority"] == "P1":
            priority = "P1"      # ปรับเป็นด่วนมาก
        if pol["escalate"]:
            escalate = True     # ต้องส่งหัวหน้า

    return priority, escalate
💡 พูดง่ายๆ: ดู Policy ที่เจอ → ถ้าบอกว่า P1 ก็ให้ P1, ถ้าบอก escalate ก็ส่งหัวหน้า

⚖️ Agent #4: Judge

def run_judge(decision, policies):
    issues = []

    # กฎ: ถ้าบอกว่า escalate ต้องมี policy รองรับ
    if decision.escalate and not policies:
        issues.append("escalation ไม่มี policy อ้างอิง")

    # กฎ: ถ้าให้ P1 ต้องมี policy รองรับ
    if decision.priority == "P1" and not policies:
        issues.append("P1 ไม่มี policy รองรับ")

    return JudgeVerdict(approved=len(issues)==0)
💡 พูดง่ายๆ: Judge = "ผู้ตรวจสอบ" ดูว่าการตัดสินใจมี Policy รองรับไหม
