📝 AI #1: NLP คืออะไร?

Natural Language Processing - สอนคอมพิวเตอร์ให้อ่านภาษาคน

NLP ทำอะไรได้?

  • อ่านข้อความภาษาไทย/อังกฤษ

  • เข้าใจความหมายของประโยค
  • จัดหมวดหมู่ข้อความ

ในระบบนี้ NLP ทำอะไร?

หาคำสำคัญใน ticket เช่น:

"ล่ม" "ใช้งานไม่ได้" → technical

"คืนเงิน" "refund" → refund

💡 NLP ช่วยอะไร? อ่าน ticket แล้วหาคำสำคัญ → บอกได้ว่าเรื่องอะไร (billing? technical? refund?)

🔢 AI #2: TF-IDF คืออะไร?

แปลงข้อความเป็นตัวเลข เพื่อหา "ความคล้าย"

1
TF = Term Frequency

คำนี้ปรากฏกี่ครั้ง?

"ระบบล่ม ล่มมาสองวัน" → "ล่ม" = 2 ครั้ง

2
IDF = Inverse Document Frequency

คำนี้หายากแค่ไหน?

"Enterprise" หายาก → สำคัญมาก!

3
TF × IDF = ความสำคัญของคำ

คำไหนสำคัญที่สุดในข้อความนี้?

ใช้ทำอะไรในระบบนี้?

ค้นหา Policy ที่เกี่ยวข้อง:

  1. แปลง Ticket เป็น Vector [0.2, 0.8, ...]
  2. แปลง Policy เป็น Vector [0.3, 0.7, ...]
  3. คำนวณ Cosine Similarity
  4. เลือก Policy ที่ "คล้ายที่สุด"
💡 TF-IDF ช่วยอะไร? หา Policy ที่ตรงกับ ticket → เช่น ticket "ระบบล่ม Enterprise" → เจอ Policy "SLA-001: Enterprise outage"

🤝 AI #3: Multi-Agent System

หลาย AI ทำงานร่วมกัน แบ่งงานกันทำ

Ticket เข้ามา │ ▼ ┌─────────────────┐ │ 🤖 Agent 1 │ NLP อ่านแล้วจัดหมวดหมู่ │ Intent Router │ "เรื่องนี้คือ technical" └────────┬────────┘ ▼ ┌─────────────────┐ │ 🤖 Agent 2 │ TF-IDF ค้นหา Policy │ Policy RAG │ "เจอ SLA-001" └────────┬────────┘ ▼ ┌─────────────────┐ │ 🤖 Agent 3 │ ให้คะแนนความเร่งด่วน │ Priority Scorer│ "P1 ด่วนมาก!" └────────┬────────┘ ▼ ┌─────────────────┐ │ 🤖 Agent 4 │ ตรวจสอบความถูกต้อง │ Judge │ "อนุมัติ ✓" └────────┬────────┘ ▼ ส่งผลลัพธ์ ✅
💡 ทำไมใช้หลาย Agent? แบ่งงาน → ตรวจสอบกันได้ → ผลลัพธ์แม่นยำขึ้น!

🤖 Agent 1: Intent Router

ใช้ NLP อ่าน ticket แล้วบอกว่าเรื่องอะไร

📥 Input (Ticket)

"ระบบล่มมาสองวัน ใช้งานไม่ได้เลย"

🧠 AI ทำอะไร?

  1. อ่านข้อความ
  2. หาคำสำคัญ: "ล่ม" "ใช้งานไม่ได้"
  3. เทียบกับ keyword แต่ละหมวด
  4. หมวด technical มี keyword ตรงมากที่สุด

📤 Output

หมวด: technical

ความมั่นใจ: 95%

📄 app/agents/rules.py
def classify(subject, body):
    text = f"{subject} {body}".lower()

    # นับ keyword แต่ละหมวด
    scores = {}
    for cat, keywords in CATEGORY_KEYWORDS:
        hits = sum(1 for kw in keywords
                   if kw in text)
        scores[cat] = hits

    # เลือกหมวดที่ได้คะแนนสูงสุด
    best = max(scores, key=scores.get)
    return best

🤖 Agent 2: Policy RAG

ใช้ TF-IDF ค้นหา Policy ที่เกี่ยวข้อง

📥 Input

Ticket: "ระบบล่ม" + หมวด: technical

🧠 AI ทำอะไร? (TF-IDF)

  1. แปลง ticket เป็น vector
  2. แปลง policy ทุกข้อเป็น vector
  3. คำนวณ cosine similarity
  4. เลือก policy ที่คล้ายที่สุด

📤 Output

เจอ Policy: SLA-001

ความคล้าย: 0.85

📄 app/agents/policy_rag.py
def search(query, k=5):
    # 1. แปลง query เป็น vector
    q_vec = vectorize(query)

    # 2. คำนวณความคล้ายกับ policy
    results = []
    for policy in all_policies:
        p_vec = vectorize(policy.text)
        score = cosine_similarity(q_vec, p_vec)
        results.append((policy, score))

    # 3. เรียงตามคะแนน
    results.sort(key=lambda x: x[1])
    return results[:k]

🤖 Agent 3 & 4: Scorer และ Judge

ให้คะแนนและตรวจสอบความถูกต้อง

🤖 Agent 3: Priority Scorer

ดู Policy แล้วกำหนด Priority

Policy SLA-001 บอกว่า:

• priority = P1

• escalate = true

→ Scorer ก็ให้ P1 + Escalate

🤖 Agent 4: Judge

ตรวจสอบว่าตัดสินใจถูกไหม

เช็คกฎ:

• ถ้า escalate → ต้องมี policy รองรับ ✓

• ถ้า P1 → ต้องมี policy รองรับ ✓

→ Judge อนุมัติ ✅

💡 ทำไมต้องมี Judge? ป้องกันไม่ให้ AI ตัดสินใจผิดพลาด → ทุกการตัดสินใจต้องมี Policy รองรับ!
